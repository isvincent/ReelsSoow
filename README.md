# 🎬 教學影片集

收錄 Reels 教學短影音的網頁集。影片放在 Google 雲端硬碟資料夾，**檔名就是影片主題**；
資料夾新增影片後，網站會透過 Google Apps Script 自動抓到新影片，**不必修改網站程式**。

- 🔍 瀏覽與即時搜尋（關鍵字高亮）、依主題系列分類、排序（預設依日期由近而遠）
- ▶️ 點卡片直接播放（9:16 直式播放視窗），上一部／下一部、鍵盤 ← → 與手機左右滑動
- ❤️ 收藏、✓ 已看標記、🏆 觀看進度條（全部看完會放彩帶）、🎲 隨機播放、🔗 分享連結
- 🔊 Web Audio 合成音效（不需音檔）、漂浮動畫、卡片動畫
- ⚙️ 顯示與操作設定：全螢幕／音效／裝置／版面／語言／字體／色系 七大切換（自動記住）
- 📱 RWD 響應式 + PWA（可安裝到主畫面、離線開啟網站外殼）

## 🚀 操作步驟

### 步驟 1：把影片設為「知道連結的人都能檢視」

訪客不需登入就能播放，影片必須公開檢視：

1. 開啟雲端硬碟資料夾 → 對資料夾按右鍵 →「共用」→「共用」。
2. 「一般存取權」改成 **知道連結的任何人**，角色為 **檢視者** → 完成。
3. 之後放進這個資料夾的新影片會自動繼承這個權限。

> 也可以在步驟 2 的 Apps Script 中執行 `shareAllVideos` 函式，一鍵設定所有影片。

### 步驟 2：建立 Google Apps Script 影片清單 API

1. 前往 <https://script.google.com> →「新專案」，專案名稱改為「教學影片集 API」。
2. 刪除預設內容，貼上 `gas/Code.gs` 的全部程式碼 → 儲存（Ctrl + S）。
3. 確認第一行設定的 `FOLDER_ID` 是你的資料夾 ID（網址 `folders/` 後面那串）。
4. 上方函式選單選 **`testList`** → 按「執行」。
   - 第一次會要求授權：「審查權限」→ 選帳號 →「進階」→「前往 教學影片集 API（不安全）」→「允許」。
   - 下方「執行記錄」會列出抓到的影片，代表成功。
5. 右上角 **「部署」→「新增部署作業」**
   - 齒輪選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**任何人**
   - 按「部署」，複製 **網頁應用程式網址**（結尾是 `/exec`）。
6. 把網址貼到瀏覽器測試，看到一串 JSON（含 `videos`）就成功了。

### 步驟 3：把 API 網址填進網站

打開 `js/config.js`，把網址貼到 `API_URL`：

```js
API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
```

> 沒填 `API_URL` 時，網站會讀 `videos.json`（目前 12 部影片的備用清單），一樣能運作，只是不會自動更新。

### 步驟 4：上傳到 GitHub 並開啟 GitHub Pages

1. 登入 GitHub → 右上「＋」→ **New repository**，名稱例如 `reels-videos`，選 **Public** → Create。
2. 在新倉庫頁面點 **uploading an existing file**，把 `Reels教學影片集` 資料夾「裡面的所有檔案與資料夾」拖進去（`index.html` 要在最上層）→ **Commit changes**。
3. 進入 **Settings → Pages**：Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾 **/(root)** → Save。
4. 約 1～2 分鐘後，網址會是：`https://你的帳號.github.io/reels-videos/`

### 步驟 5：之後新增影片

只要把影片（例如 `光合作用.mp4`）上傳到雲端硬碟資料夾即可。
網站每次開啟都會即時讀取資料夾，新影片重新整理就會出現（依「上傳日期」排在最前面）；
網頁開著時每 3 分鐘、或切回網頁時也會自動檢查新影片。

- 檔名 = 影片標題；`颱風_A`、`颱風_B`、`圓周率1`、`圓周率2` 會自動歸為同一系列的分類標籤。
- 在雲端硬碟對影片按右鍵 →「檔案資訊」→「詳細資料」填寫 **說明**，會顯示在播放視窗。
- 資料夾內可以建立 **子資料夾**，子資料夾名稱會變成分類。
- 想替新主題設定專屬圖示與配色，在 `js/config.js` 的 `TOPIC_STYLES` 加一行即可。

> ⚠️ 修改 `Code.gs` 後要重新部署：「部署」→「管理部署作業」→ 鉛筆 → 版本選「新版本」→ 部署（網址不變）。

## ❓ 常見問題

- **影片出現 Google「登入」畫面** → 影片沒有公開，請做步驟 1。
- **縮圖只顯示彩色圖示** → 雲端硬碟尚未產生縮圖或影片未公開；網站會自動改用主題配色卡片。
- **新影片沒出現** → 按 🔄；仍沒有，確認影片在正確資料夾、Apps Script 部署的存取權為「任何人」。
- **網站改了沒更新（PWA 快取）** → 重新整理一次即可；必要時把 `sw.js` 的 `VERSION` 改成 `reels-v2`。
- **本機測試** → 需用本機伺服器開啟（例如 `python -m http.server`），直接雙擊 `index.html` 無法讀取 `videos.json`。
